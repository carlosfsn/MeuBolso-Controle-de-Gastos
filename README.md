# 💜 MeuBolso — Controle de Gastos

O **MeuBolso** é um aplicativo Android de gerenciamento financeiro pessoal, desenvolvido com o objetivo de facilitar o registro, a organização e o acompanhamento de receitas e despesas.

Com uma interface intuitiva e uma identidade visual em tons de rosa e roxo, o aplicativo busca tornar o controle financeiro mais simples, acessível e organizado.

## 📱 Funcionalidades

### Dashboard
- Visualização do saldo financeiro.
- Resumo de receitas e despesas do mês.
- Gráfico de acompanhamento financeiro.
- Exibição das últimas movimentações cadastradas.

### Nova Movimentação
- Cadastro de receitas e despesas.
- Categorias específicas para cada tipo de movimentação.
- Formatação automática de valores monetários.
- Seleção de datas pelo calendário.
- Validação dos campos obrigatórios.
- Armazenamento das movimentações no SQLite.

### Histórico
- Consulta às movimentações cadastradas.
- Filtros por receitas e despesas.
- Seleção do mês de referência.
- Ordenação por data.
- Visualização dos detalhes de cada movimentação.

### Categorias
- Visualização das categorias de receitas e despesas.
- Acompanhamento dos valores registrados por categoria.
- Consulta à quantidade de movimentações.
- Identificação visual por ícones.

### Perfil
- Visualização das informações do usuário.
- Edição local de nome e e-mail.
- Acesso às opções de configurações.
- Retorno à tela de login.

## 🛠️ Tecnologias utilizadas

- **Java:** implementação da lógica do aplicativo.
- **XML:** desenvolvimento das interfaces Android.
- **SQLite:** armazenamento local das movimentações financeiras.
- **Android Studio:** ambiente de desenvolvimento.
- **Git e GitHub:** controle de versões e gerenciamento do código-fonte.

## 📂 Estrutura do aplicativo

O projeto possui as seguintes telas principais:

- Login
- Criar Conta
- Início (Dashboard)
- Nova Movimentação
- Histórico
- Categorias
- Perfil

O gerenciamento do banco de dados é realizado pela classe `BancoDadosHelper.java`.

## 🚀 Como executar

1. Clone ou baixe este repositório.
2. Abra o projeto no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Conecte um dispositivo Android ou configure um emulador.
5. Execute o aplicativo.

## 🚧 Status do projeto

**Em desenvolvimento.**

As principais interfaces estão implementadas e as movimentações financeiras são armazenadas localmente com SQLite.

Ainda estão previstas melhorias como autenticação real de usuários, ampliação das configurações e aperfeiçoamento das funcionalidades financeiras.

**Observação:** as telas de Login e Criar Conta ainda não possuem autenticação real. Os dados financeiros são armazenados localmente no dispositivo.
